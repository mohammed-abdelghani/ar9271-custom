# 📡 الحالة الحالية للكارت على هذا الجهاز (لقطة حيّة)

> **تاريخ الالتقاط:** 2026-11-13 — 18:59 EET
> **النظام:** Debian GNU/Linux — نواة `6.12.116+deb13-amd64`
> **النتيجة العامة:** ✅ الكارت متصل فعلياً ومنطّق (bound) بالدرايفر وجاهز للاستخدام.

---

## 1️⃣ وجود الجهاز على الـ USB (من `lsusb`)

```
Bus 002 Device 005: ID 0cf3:1006 Qualcomm Atheros Communications
                       TP-Link TL-WN322G v3 / TL-WN422G v2 802.11g [Atheros AR9271]
```

| الحقل (sysfs) | القيمة |
|---|---|
| مسار الجهاز | `/sys/bus/usb/devices/2-1.4` |
| Bus / Device | `002` / `005` |
| idVendor : idProduct | `0cf3` : `1006` |
| manufacturer / product | `ATHEROS` / `USB2.0 WLAN` |
| السرعة | 480 Mbps (USB 2.0 High Speed) |
| bMaxPower | 500 mA |
| bcdDevice | `0108` |

## 2️⃣ الإنترفيس الشبكي

| الحقل | القيمة |
|---|---|
| **اسم الإنترفيس** | `wlx001122334455` |
| **MAC** | `00:11:22:33:44:55` (قيمة مُعمّاة للنشر — بادئة TP-Link) |
| **phy** | `phy2` |
| **الدرايفر المرتبط** | `ath9k_htc` (`/sys/class/net/wlx001122334455/device/driver` → `bus/usb/drivers/ath9k_htc`) |
| **حالة الواجهة** | `UP` لكن `NO-CARRIER` — أي الواجهة مفعّلة لكن الكارت **غير متصل بأي شبكة حالياً** |

الاسم `wlx001122334455` ليس عشوائياً: لينكس يسمّي كروت الـ USB اللاسلكية بالصيغة `wlx` + عنوان MAC بدون نقطتين (القيم هنا مُعمّاة — اسم إنترفيسك الفعلي مشتق من MAC جهازك).

## 3️⃣ حالة الشبكة (من `nmcli`)

```
DEVICE                  TYPE      STATE          CONNECTION
wlp2s0                  wifi      connected      …          ← واي فاي اللابتوب الداخلي (Intel) — هو المتصل بالإنترنت
wlx001122334455         wifi      disconnected   --          ← ⬅ هذا الكارت: متصل بالجهاز لكن غير موصول بشبكة
p2p-dev-wlx001122334455 wifi-p2p  disconnected   --
```

**الخلاصة:** الكارت **شغّال ومعترَف به بالكامل** (جهاز USB + درايفر + فيرموير + إنترفيس شبكي)، لكنه حالياً **مستني** وغير متصل بأي شبكة واي فاي. أما الإنترنت الحالي على الجهاز فآتٍ من واي فاي اللابتوب الداخلي (`wlp2s0`).

## 4️⃣ حالة الدرايفَر والفيرموير

| البند | الحالة |
|---|---|
| الموديولات محمّلة؟ | ✅ `ath9k_htc`, `ath9k_common`, `ath9k_hw`, `ath`, `mac80211`, `cfg80211` |
| الفيرموير `htc_9271-1.4.0.fw` موجود؟ | ✅ في `/lib/firmware/ath9k_htc/` |
| باراميترات التشغيل | `blink=1`, `ps_enable=0`, `nohwcrypt=0` (إعدادات افتراضية سليمة) |

## 5️⃣ الأدوات الغائبة على هذا الجهاز ⚠️

الفحص أظهر أن الأدوات التالية **غير مثبّتة**:

- `iw` — أداة التحكم في nl80211 (المثيلة للـ iwconfig الحديثة)
- `iwconfig` — أداة wireless-tools القديمة
- `airmon-ng` — من حزمة aircrack-ng

للتثبيت عند الحاجة (مثلاً لتجربة Monitor Mode):

```bash
sudo apt install iw wireless-tools aircrack-ng
```

## 6️⃣ كيف تتأكد بنفسك في أي وقت؟

```bash
# هل الكارت موجود على الـ USB؟
lsusb | grep -i 0cf3:1006

# هل الإنترفيس موجود ومرتبط بالدرايفر؟
ls -l /sys/class/net/wlx001122334455/device/driver

# ما حالة الشبكة؟
nmcli device status
```
