# 📟 المواصفات الفنية — TP-Link TL-WN422G v2 (Atheros AR9271)

## 1️⃣ مواصفات الكارت كما هو مُصنَّف رسمياً

| المواصفة | القيمة |
|---|---|
| **الموديل** | TP-Link TL-WN422G v2 |
| **الاسم التسويقي** | 54Mbps High Gain Wireless USB Adapter |
| **الشريحة (Chipset)** | Qualcomm Atheros AR9271 |
| **معايير الشبكة** | IEEE 802.11g، IEEE 802.11b |
| **أقصى سرعة لاسلكية** | 54 Mbps (802.11g) / 11 Mbps (802.11b) |
| **نطاق التردد** | 2.4 – 2.4835 GHz (‏2.4 GHz فقط — لا يدعم 5 GHz) |
| **الهوائي** | خارجي قابل للفصل، Omni-directional 4 dBi |
| **موصل الهوائي** | RP-SMA |
| **واجهة التوصيل** | USB 2.0 Type-A Male (مباشرة في المنفذ) |
| **التشفير** | WEP (64/128-bit)، WPA-PSK، WPA2-PSK (TKIP/AES) |
| **حالة الإنتاج** | متوقف عن الإنتاج (EOL) — التعريفات الرسمية تصل حتى Windows 7 |

## 2️⃣ عن شريحة Qualcomm Atheros AR9271

- شريحة **USB Wireless NIC** من Atheros (صار اسمها لاحقاً Qualcomm Atheros بعد الاستحواذ).
- سيليكون الشريحة نفسها مبني على معيار **802.11n** ويستخدم في أجهزة أخرى مثل TP-Link **TL-WN722N** (‏150 Mbps) — لكن هذا الموديل (WN422G v2) مُصنَّف تسويقياً كـ **802.11g**.
- تُعرف بشعبية كبيرة بين مستخدمي لينكس لأنها تعمل بالدرايفر المفتوح المصدر **`ath9k_htc`** المدمج في النواة، وتدعم **Monitor Mode و Packet Injection** (مفضّلة جداً في أدوات مثل aircrack-ng).
- تحتاج **فيرموير خارجي** يُحمَّل على الشريحة عند التشغيل: `htc_9271-1.4.0.fw`.

---

## 3️⃣ الهوية على منفذ USB (مأخوذة من هذا الجهاز فعلياً)

| الحقل | القيمة (من sysfs) |
|---|---|
| **Vendor ID** | `0cf3` — Qualcomm Atheros Communications |
| **Product ID** | `1006` — TL-WN322G v3 / TL-WN422G v2 |
| **اسم الجهاز المُبلَّغ** | `ATHEROS USB2.0 WLAN` |
| **الشركة المصنّعة المُبلَّغة** | `ATHEROS` |
| **سرعة منفذ USB** | 480 Mbps (High Speed / USB 2.0) |
| **أقصى استهلاك للطاقة** | 500 mA |
| **bcdDevice** | `0108` (رقم المراجعة المُبلَّغ من الفيرموير الداخلي) |

> 📌 الـ USB ID نفسه (`0cf3:1006`) مشترك بين **TL-WN322G v3** و **TL-WN422G v2** — النواة لا تفرّق بينهما لأنهما نفس العتاد تقريباً.

## 4️⃣ عنوان MAC

- عنوان MAC الخاص بهذه الوحدة: **`f8:d1:11:b3:7c:15`**
- البادئة `f8:d1:11` مسجّلة رسمياً باسم **TP-Link Technologies Co.,Ltd.** (وهذا من أدلة أصالة الجهاز).
- لاحظ أن اسم الإنترفيس على لينكس مشتق من الـ MAC: `wlx` + `f8d111b37c15` = `wlxf8d111b37c15`.
