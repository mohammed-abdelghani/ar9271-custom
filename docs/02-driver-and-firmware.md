# 🐧 الدرايفَر والفيرموير على لينكس — ath9k_htc

## 1️⃣ نظرة عامة

الكارت يعمل على لينكس بالدرايفر **`ath9k_htc`** المدمج في النواة (لا يحتاج تثبيت أي شيء من خارج النواة عدا ملف الفيرموير):

```
ath9k_htc  →  ath9k_common  →  ath9k_hw  →  ath  →  mac80211  →  cfg80211
   ↑
شريحة AR9271 عبر USB
```

## 2️⃣ معلومات الموديول (من `modinfo` على هذا الجهاز)

| الحقل | القيمة |
|---|---|
| **filename** | `/lib/modules/6.12.116+deb13-amd64/kernel/drivers/net/wireless/ath/ath9k/ath9k_htc.ko.xz` |
| **description** | Atheros driver 802.11n HTC based wireless devices |
| **license** | Dual BSD/GPL (مفتوح المصدر) |
| **author** | Atheros Communications |
| **الفيرموير المطلوب** | `ath9k_htc/htc_9271-1.4.0.fw` (لهذه الشريحة) |
| | `ath9k_htc/htc_7010-1.4.0.fw` (لشريحة AR7010 الأخرى) |

## 3️⃣ ملفات الفيرموير الموجودة فعلاً على هذا الجهاز

```
/lib/firmware/ath9k_htc/htc_9271-1.4.0.fw   ← ✅ الفيرموير المطلوب للـ AR9271 (موجود)
/lib/firmware/ath9k_htc/htc_7010-1.4.0.fw   ← فيرموير AR7010 (غير مستخدم هنا)
/lib/firmware/htc_9271.fw                    ← نسخة قديمة بالمجلد الرئيسي (legacy path)
```

على Debian، ملفات الفيرموير هذه تأتي من حزمة:

```bash
sudo apt install firmware-atheros   # (repo: non-free-firmware)
```

## 4️⃣ باراميترات الموديول وحالتها الحالية على هذا الجهاز

الباراميترات متاحة في: `/sys/module/ath9k_htc/parameters/`

| الباراميتر | القيمة الحالية | الوظيفة |
|---|---|---|
| `blink` | `1` | تشغيل وميض LED عند نشاط الشبكة |
| `btcoex_enable` | `0` | تعطيل/تفعيل التعايش مع Bluetooth (لا علاقة له بجهاز بلا بلوتوث) |
| `nohwcrypt` | `0` | ‏`0` = تشفير العتاد مفعّل (الأفضل)، `1` = فرض التشفير البرمجي |
| `ps_enable` | `0` | ‏`0` = إيقاف Power Save (أفضل ثباتاً وأداءً) |
| `use_dev_fw` | `0` | ‏`0` = استخدام فيرموير النظام بدل فيرموير مضمّن بالجهاز |

لتغيير قيمة مؤقتاً (مثال):

```bash
echo 1 | sudo tee /sys/module/ath9k_htc/parameters/nohwcrypt
```

ولجعلها دائمة، أضف في `/etc/modprobe.d/ath9k_htc.conf`:

```
options ath9k_htc nohwcrypt=1 ps_enable=0
```

## 5️⃣ قدرات مهمة على لينكس

| القدرة | الحالة |
|---|---|
| **Managed Mode** (الاتصال بشبكات عادية) | ✅ مدعوم |
| **Monitor Mode** | ✅ مدعوم — من أشهر الكروت للاختبارات الأمنية المصرّح بها |
| **Packet Injection** | ✅ مدعوم (مع فيرموير 1.4.0) |
| **AP Mode (نقطة وصول)** | ✅ مدعوم عبر hostapd |
| **5 GHz** | ❌ غير متاح — العتاد 2.4 GHz فقط |

## 6️⃣ ملاحظات توافقية

- الدريفر مدمج في النواة منذ إصدارات `2.6.3x` فما بعد، وأي نواة حديثة تعمل به مباشرة.
- من المفضل توصيل الكارت في منفذ **USB 2.0** — منافذ USB 3.0 معروفة أنها تُحدث تداخلاً على تردد 2.4 GHz وقد تُضعف الإشارة.
- هذا الجهاز لا يحتاج أي تعريف منفصل على لينكس — إن لم يعمل فالمشكلة غالباً في **فقدان ملف الفيرموير** (راجع وثيقة استكشاف الأخطاء).
